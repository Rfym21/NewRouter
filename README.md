# New Router

https://github.com/Rfym21/WorkSpace/tree/main/Projects/NewRouter (Current)

https://github.com/QuantumNous/new-api (Upstream)

当前同步基准：官方 `main` 的 Commit(`8c8940c999c6c38031dacdd0139cf7b0e1c38308`)，同步日期 2026-11-07。

最初基于 Commit(`4e570389dd433a717373ce9c9b822b59f5ed3d5d`) 二次开发。

本次同步包含上次基准 `45746eee4de25ab1eb75d4b7fbb8de2199483ea3` 之后的 14 个官方提交，保留 New Router 的渠道标签权限、计费扩展、模型与响应去匿名化、日志异步导出和分享、审计日志二次验证清除，以及自定义前端。

- 修复用户与令牌 Redis 缓存跨槽错误，并为鉴权缓存加入完整性校验；双因素认证锁定过期后重新开始失败计数。
- 模型价格保存前先审阅变更，并对缺失或失效的插件价格给出处理引导。
- Gemini Embeddings 改按上游 `usageMetadata` 计费，Gemini 补 Argon 字段与 reasoning 映射；Vertex 服务账号访问令牌按过期时间缓存，并支持渠道级 `v1beta1` 端点切换。
- AWS 移除未用的 API Key HTTP 请求路径；`gpt-image-2.6` 转发 `complexity`、`markup` 等字段；上传插件在顶层 `/v1` 路径服务；渠道创建返回 ID 与输入映射。

- 修复 Grok 流式响应丢失缓存和输出 Token 明细的问题，缓存命中可按配置的缓存价格计费。
- Gemini Omni 按输入、文本输出（含思考）、视频（含音频）Token 计费：提交时估算视频 Token，完成后按 Vertex AI 返回的实际用量结算。新的 Token 计费配置需要兼容的表达式，旧按次价格、倍率价格或依赖 `u("seconds")`、`u("resolution")` 等旧字段的表达式需要在模型价格设置中重新配置；不兼容请求会在估价、预扣和提交前拒绝，已提交任务继续按冻结的价格及用量快照结算。
- HTTP/2 上游连接支持可选 PING 健康检查，默认关闭；通过 `RELAY_HTTP2_PING_IDLE_TIMEOUT` 和 `RELAY_HTTP2_PING_TIMEOUT` 配置，检测失联连接而不影响正常应答的慢请求。
- 日志最长查询范围与最大导出跨度合并为一个设置，普通用户的日志查询、仪表盘和所有日志导出共用该限制。新安装默认 30 天，升级时按原有两个设置的较严格值归并，旧导出配置键继续作为兼容别名。
- 上游价格同步增加价格状态筛选，可查看全部模型、仅未设置价格模型或仅价格不一致模型；后两种筛选以本站渠道和精确模型记录中的已有模型为范围，支持精确匹配及模糊匹配上游模型名，多个模糊候选需分别选择，价格保存到本站模型。零价视为已设置，界面显示被筛选隐藏的已选模型数量。
- 用量和错误日志显示匿名化处理数量，仅记录计数；参数覆盖日志省略具体值，诊断信息遮蔽已知敏感原文。日志列设置支持独立遮蔽每列内容并保留表头，偏好按账号和视图保存，桌面、移动端与审计视图共用该行为。
- 匿名化新增稳定假名模式，可在请求策略页开关：同一敏感值在同一用户和令牌内映射到固定假值，完整重发历史的客户端（如 Claude Code）可正常命中上游提示词缓存；假值由实例密钥按用户和令牌派生，跨身份不可关联，默认仍为每请求随机。
- 匿名化上下文的闲置有效期与引用数上限可在运行时设置页调整，保存后热生效；原环境变量仅作为初始默认值。

此前同步的功能继续保留：

- 原生插件路由已向客户端转发流式事件后，补扣额度或写入任务失败时不再全额退款，改为按实际额度结算并记录消费日志；Kling 4.0 现金扣费按返回的 `list_price` 计费。
- Vertex AI 渠道支持 Gemini Omni Flash 视频生成，Veo 继续使用 New Router 的时长读取和 4K 预扣倍率。
- 请求 JSON 的读取和改写改用 moego，base64 处理同步替换；参数覆盖、禁用字段过滤、Responses WebSocket、AWS Mantle 与透传请求只改动目标字段，其余字段保留客户端原有顺序和写法，重复出现的键会全部移除或改写。禁用字段过滤继续遵循渠道请求体字段规则。

- 任务插件支持供应商原生路径、原生响应和流式接口，补充 multipart 请求及客户端请求头传递；共享插件接口可参与普通渠道选择，保留按插件前缀访问的方式。
- 修复 Claude 缓存写入计费，支持 OpenAI 12 小时缓存写入及 `cc12h` 表达式；任务每次重试重新预扣，价格同步可按本站汇率乘除调整。
- 改善 Claude、Gemini、OpenAI Responses 的工具调用和 JSON Schema 转换，修复已完成流误判断开、大事件向慢客户端传输时截断，以及非流式请求取消后的计费。
- 支持阿里多模态 embedding，修复 Kling 单 API Key 和视频时长、尺寸处理，默认任务超时调整为 72 小时。
- 仪表盘加入缓存读写用量，插件界面提示缺少计费价格的模型；修复编辑抽屉残留字段、退出后重复请求、侧边栏可见性及 Turnstile 设置保存。
- 加入请求解压内存限制、访问日志凭据脱敏和任务查询跳转凭据保护，修复日志轮转写入；升级 Go、Bun、DOMPurify、图表库及其他依赖。
- 支持 DeepSeek V4.1 Flash、Search / Fetch 接口及推理参数，加入对应搜索、抓取和时段计费。
- AWS 渠道增加 Mantle Messages API；Vertex API Key 模式支持 Project ID，并修复 `us` / `eu` 多区域地址。
- Hailuo、Vidu、Veo 视频插件支持 New API 渠道；修复 Vidu 参数覆盖导致的计费不一致，并升级 moejs 到 alpha.7。
- 渠道列表支持拖拽调整优先级，预览、移动和撤销均遵循管理员渠道标签权限。
- 邮件支持 Resend；各类通知可独立开关，修复通知限流窗口和低余额提醒重复发送。
- 修复 Claude 缓存计费、分组限流、容器过载判断及流式请求准备和重试期间的保活，并保留自定义去匿名化与计费设置。
- 日志维护与导出设置整合到 `/system-settings/operations/logs`，旧导出设置地址自动跳转。审计日志总开关 `AuditLogEnabled` 默认开启，关闭后停止新增审计记录，已有记录与用量日志不受影响。超级管理员可按时间清除审计记录，操作需要绑定该时间的单次身份验证，审计开启时保留清除事件。
- 文本匿名化支持自定义关键词与正则规则、匹配预览、中文格式校验和可选 Presidio；补齐各协议工具参数的流式还原，以及 Responses/compact 的用户与令牌隔离映射。配置方式和保护范围见 [匿名化说明](docs/anonymization.md)。
- 更新检测与发布说明链接使用 `Rfym21/NewRouter` 的 GitHub Releases，并隔离旧上游版本缓存。

日志导出统一使用 New Router 的选列弹窗，提供后台压缩 CSV 任务和直接下载 CSV。后台任务保留导出记录、过期清理、分享及管理功能，复用官方逐行读取与日志列表筛选逻辑，避免按 ID 分页在 ClickHouse 下遗漏记录；两种导出均跟随当前视图范围和上游请求 ID 筛选，并补充缓存读写、流式和请求 ID 列及 CSV 公式转义。

- 面板访问令牌支持独立名称、有效期和权限范围；管理员敏感操作加入二次验证，并与现有 Casbin 权限保持一致。
- 任务插件迁移到 moejs，支持 `utils.fetch`、JSON 字段顺序和自动视频时长；更新 Seedream，并加入 xAI 视频插件。
- 加入 TokenKit，修复 Responses、Chat、Claude、Gemini 协议转换和联网搜索计费。
- 日志支持直接 CSV 下载、查询时间范围设置和消息国际化；原有异步压缩导出、分享及管理员管理继续保留。
- 更新日期时间选择、字体、图标、渠道刷新、用户分组筛选、账号独立 Playground 数据及相关依赖。

构建需要 Go 1.26.10 或更高版本，前端使用 Bun 1.4.4。旧面板访问令牌在新版首次启动后有 30 天迁移期；可在安全设置中创建新的权限令牌。默认消息和服务端日志语言可通过 `DEFAULT_LANGUAGE` 设置。

GitHub Actions 支持手动运行，或在 `main` 分支的 `VERSION` 文件变化时，编译六个平台的可执行文件、发布 GitHub Releases，并推送 Linux 双架构镜像到 GHCR。触发方式、版本格式和镜像使用方法见 [编译与发布说明](.github/README.md)。
